# Cybersecurity-Threat-Analysis

An interactive global cybersecurity threat analysis dashboard built with Power BI.

## Dashboard screenshots

### 1. Global overview

![Global dashboard overview](Image/Screenshot%202026-11-17%20155815.png)

The dashboard opens with all slicers set to **All**. It summarizes losses, affected users, attacks, and average resolution time, with breakdowns by country, attack type, target industry, and defense mechanism.

### 2. Focused slicer selection

![Australia, Business, and Malware filters applied](Image/Screenshot%202026-11-17%20160048.png)

Selecting **Australia** for Country, **Business** for Target Industry, **Hacker Group** for Attack Source, and **Malware** for Attack Type filters the report to matching records. The KPI cards, charts, and table update to show the results for that selection.

### 3. Multiple slicer selections

![Multiple slicer selections with Average Effected User selected](Image/Screenshot%202026-11-17%20160224.png)

With multiple values selected in Country, Target Industry, Attack Source, and Attack Type, the dashboard aggregates the matching records. The **Average Effected User** metric button is selected, and the KPI cards and visuals reflect the filtered data.

### 4. Multiple selections including Year

![Multiple slicer selections including Year](Image/Screenshot%202026-11-17%20160310.png)

This view also uses multiple selections in the **Year** slicer. The table shows the matching years, while the country, industry, attack-type, and defense-mechanism charts update to reflect the combined filters. **Average Effected User** remains selected.
